# Release: mxcli v0.33.0

*November 22, 2026*

v0.33.0 is about **catching more before the build, native mobile apps, and four new lint rules that read your model's design**.

## What's new

**Native mobile navigation and widgets.** `create navigation NativePhone { … }` creates a native navigation profile with its bottom bar, so a home page whose layout needs one no longer stops at CE6108. The bottom bar is flat and page-only, with glyph icons. Native Image, Signature, Bottom sheet and Maps widgets that mxcli creates now build without CE0463 on Native Mobile Resources 12.6.0. `check` warns about a pluggable widget on a page of the other platform (MDL-WIDGET55) and about a required widget setting left unset (MDL-WIDGET56). `describe` names a native widget by its own keyword, such as `nativegallery`.

**`check` type-checks more of a microflow.** A value of the wrong type in a `declare`, `set` or `return`, an expression that reads a variable nothing defines, `returns T as $R` when a path ends the flow without `$R`, a primitive where a list operation needs an object or a list, and `replace(…)`, which is not a Mendix expression function, are all refused by `check` instead of failing in mxbuild. Entity-level mistakes are caught too: `check -p` rejects dropping an attribute, entity or association that a document still uses, and `owner both` between an entity and itself or its generalization.

**Four new lint rules.** Each reports something that `mx check` and the build are clean on:

- `MPR016`: entities whose boxes cover each other on the domain model diagram. `mxcli layout --only-overlapping` repairs it.
- `MPR017`: a Boolean flag that a decision tests but which can only ever hold one value, so the guarded branch is unreachable.
- `MPR018`: a model element named inside a string literal, which a rename or move leaves dangling.
- `MPR019`: an attribute an XPath constraint filters on that no index leads with.

**Edit one operation, one message.** `alter published rest service … add operation in resource '<name>' { … }` and `drop operation <method> ['<path>'] in resource '<name>'` change one operation of a stored resource without restating the service. A business event message's operations are now its children, so one message can both publish and subscribe: `message X (…) { publish (…); subscribe (…); };`.

**Studio Pro opens what mxcli wrote without rewriting it.** mxcli writes an element's keys in Studio Pro's order, so Studio Pro no longer rewrites a module's security or a JavaScript action call on the first open. `mxcli new` also says that the first Studio Pro open may convert the project.

**Safer by default.** `mxcli sql` is read-only unless you pass `--write`. Parallel `mxcli exec` runs on one project take a write lock instead of losing each other's writes. Nightly builds are published under their dated tag and can be pinned and rolled back.

## Upgrading

Download the `v0.33.0` binary for your platform from the [release page](https://github.com/mendixlabs/mxcli/releases/tag/v0.33.0):

```bash
curl -fsSL -o mxcli \
  https://github.com/mendixlabs/mxcli/releases/download/v0.33.0/mxcli-linux-amd64
chmod +x mxcli && sudo mv mxcli /usr/local/bin/
```

Then refresh a project's skills and commands with `mxcli init --sync-skills`.

Behaviour changes worth knowing:

- An agent with a `Model` but no `SelectedModel` is an error in `check` and `exec` (MDL-AGENT02, Studio Pro's AE018), not a warning. Add `SelectedModel: '<model id>'`.
- `mxcli sql` refuses a statement that is not a read unless `--write` is given, and runs a read in a read-only transaction.
- A script that writes holds `.mxcli/write.lock`. A second writer waits up to 60 seconds, then changes nothing and exits 75, naming the holder.
- `create or modify published rest service` naming only a new operation still replaces the stored ones, but `check` and `exec` now warn with the operations removed (MDL-REST06).
- Declaring a business event message twice, once per operation, is refused. Use one message with both operations.
- The catalog schema moves to version 50, so a cached catalog is rebuilt once.
