# Release: mxcli v0.34.0

*November 27, 2026*

v0.34.0 is about **Mendix 11.17, domain model diagrams that read well, and pluggable widgets judged the way Studio Pro judges them**.

## What's new

**Mendix 11.17.** 11.17 changed how several documents are stored, and mxcli now writes each one in the shape 11.17 reads:

- A workflow activity's boundary events live in containers, timer events are named `boundaryEvent1`, `boundaryEvent2`, …, and a microflow's notify target uses a new key. Writes are raised to the shape `mx convert` produces, byte for byte on the measured workflow, and a re-run keeps each timer's stored name.
- Pages are no longer rewritten on every run for the popup close behaviour and widget text overrides that 11.17 adds.
- Change data capture services no longer fail CE1585. A service can also track an `owner Both` association now, and `check` reports the shapes mxbuild refuses.
- `run --local --watch` no longer copies `deployment/web` aside, because 11.17 fixes the mxbuild behaviour the copies worked around. If a build loses its pages after all, mxcli turns the copies back on and rebuilds once.

**`mxcli layout` untangles a domain model.** It puts each entity on the row of the entity it links to most, puts a lookup next to what uses it, sizes each column gap to its association names, and orders columns for the fewest crossings. It also re-attaches every association line instead of leaving its connection points where they were dragged for the old positions. Box sizes are now measured from what Studio Pro draws, not estimated. Three lint rules check the result:

- `MPR020` (error): a domain model that was never laid out, so `mxcli lint` and `mxcli verify` fail on it. `exec` also names the module and the command at the end of the script.
- `MPR021` (warning): a line that runs through an entity it doesn't connect. On PizzaV1 it reports 27 findings as generated and 1 after `mxcli layout`.
- `MPR022` (error): an agent document that names a document the project doesn't have. Studio Pro keeps these names in step, but `mx` and mxbuild never check them.

**Pluggable widgets run their own `editorConfig.js`.** mxcli used to read a widget's hide logic from the bundle's source, which covered part of most widgets and none of one that hides through its own helper. It now runs the package's `getProperties` in an embedded interpreter, as Studio Pro does. The interpreter has no file, network or process access, and a call is stopped after a second. `check` now reports a hidden value it used to pass, such as Image's `iconSize` outside icon mode, and a property Studio Pro shows is no longer treated as hidden.

**More of a microflow in MDL.**

- Metrics activities: `increment counter <name> [by <value>]` and `set gauge <name> to <value>`, reported through Micrometer to OpenTelemetry, Prometheus and the other registries. `mxcli syntax microflow.metrics` has the details.
- `@documentation 'text'` on an activity, decision or loop, so a `describe` → `create or modify` round trip keeps it.
- `@curve(true: (…), false: (…))` gives each decision outcome its own curve.

**`check` catches more.** It refuses an entity named with a reserved word (MDL021), an aggregate over an attribute that isn't a number, a Java action call that leaves out a required parameter, a rule call inside a larger decision condition, and a web widget on a native page. It warns about an agent `UsageType` Agent Editor doesn't import (MDL-AGENT05) and a loop body written in canvas coordinates. `rename module` now also renames the module inside XPath constraints, expressions and view entity OQL.

## Upgrading

Download the `v0.34.0` binary for your platform from the [release page](https://github.com/mendixlabs/mxcli/releases/tag/v0.34.0):

```bash
curl -fsSL -o mxcli \
  https://github.com/mendixlabs/mxcli/releases/download/v0.34.0/mxcli-linux-amd64
chmod +x mxcli && sudo mv mxcli /usr/local/bin/
```

Then refresh a project's skills and commands with `mxcli init --sync-skills`.

Behaviour changes worth knowing:

- A bare `save changes` or `cancel changes` now closes the page, as Studio Pro's default does. Write `with (ClosePage: false)` to keep the page open. `describe` prints both forms explicitly.
- `MPR020` is an error, so `mxcli lint` and `mxcli verify` fail on a domain model that was never laid out. Run `mxcli layout --module <Module>` to clear it.
- `check` now refuses values the widget's own editor hides, which the build would reject with CE0463. A script that used to pass may need such a value removed.
- An entity named `Owner`, `Type`, `Object`, `Context`, `CreatedDate` or another platform-reserved word is refused, quoted or not.
- The catalog schema moves to version 52, so a cached catalog is rebuilt once.
