# Release: mxcli v0.32.0

*November 15, 2026*

v0.32.0 is about **speed on large projects, and giving lint rules and the catalog much more of your model to look at**.

## What's new

**Large projects are much faster.** MDL parsing is several times faster: `check` of a 600-page script without a project went from 4.5 s to 0.4 s, and re-running a settled script of 600 `create or modify microflow` statements from 23.3 s to 7.5 s. Beyond the parser, `check`, `create`, `create or modify microflow` and `describe page` no longer decode the whole project to resolve one entity, one microflow or one name, and a script reads each document once instead of once per statement. A `check` of five statements on a project of 5,373 units dropped from 2.0 s to 0.9 s. `make bench` and a nightly benchmark with a trend and an alert now watch for regressions.

**A faster dev loop and test loop.** `run --local --watch` applies a change in about 5 s instead of 20-28 s on Mendix versions that bundle the client themselves, and an open browser tab shows a page edit without a restart or a new login. `mxcli test --attach` runs a `.test.mdl` test against an app started with `--allow-call` without building anything: 0.26 s against 3.2 s for inject-and-build on a small app. `mxcli test --local --reuse-build` boots the previous build when nothing changed.

**More of the model for lint rules and the catalog.** New Starlark functions and catalog tables:

- `workflows()` / `workflow_activities()` and `CATALOG.WORKFLOW_ACTIVITIES`
- `flows_for()` and `CATALOG.FLOWS`: a flow's sequence flows and each activity's place on the canvas
- `annotations()`, `folders()` and `jar_files()`
- a widget's caption and tooltip in every language, and an enumeration value's `id`
- `AGENT_TOOLS`, `AGENT_KNOWLEDGE_BASES`, `AGENT_MCP_SERVICES`, `PUBLISHED_MCP_SERVICES` and each agent's settings, and agent prompts in full-text search

**Agents and brains.** `check` warns when an agent's name, description or tool text is longer than Agent Commons stores (MDL-AGENT04), a consumed MCP service written by mxcli now connects, and re-running an agent script keeps its Agent Editor test sets. `brain capture --from-json` and `brain promote <id>...` accept many entries as one act, and a new `genai-runtime` skill covers the runtime side of Agents Kit 2.

**`check` catches more before the build.** Unknown `[%Token%]` names, members a widget expression names, an unknown design property or option, `empty` in view entity OQL, and `show message information (…)` are now refused by `check` instead of failing the build. `alter module … add jar dependency if not exists (…)` lets a script run twice.

**Round trips that leave things alone.** Many pages and flows that `describe` → `exec` used to rewrite, or refuse, now come back unchanged: icon images, a data view's "no entity" message, a check box's label position, a JavaScript action's indentation, documentation holding `*/`, and a flow written by an earlier release.

## Upgrading

Download the `v0.32.0` binary for your platform from the [release page](https://github.com/mendixlabs/mxcli/releases/tag/v0.32.0):

```bash
curl -fsSL -o mxcli \
  https://github.com/mendixlabs/mxcli/releases/download/v0.32.0/mxcli-linux-amd64
chmod +x mxcli && sudo mv mxcli /usr/local/bin/
```

Then refresh a project's skills and commands with `mxcli init --sync-skills`.

Behaviour changes worth knowing:

- An unknown design property or option is an error in `check` and `exec` writes nothing (it was a warning); an old name of a renamed property is still a warning.
- `mxcli git merge` exits **3** when it stops for a decision (a model conflict left open, or text conflicts to resolve), and 1 only for a failure.
- `docker build`, `docker run` and `docker reload` check and build the project as stored: a stale widget definition now fails the build instead of being fixed on a temporary copy. Use `--update-widgets` for the old behaviour.
- A catalog build prints its per-table lines only on a terminal, and `-q` / `--quiet` works on every command.
- The catalog schema moves to version 48, so a cached catalog is rebuilt once.
