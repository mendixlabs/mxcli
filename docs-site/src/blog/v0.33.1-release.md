# Release: mxcli v0.33.1

*November 23, 2026*

v0.33.1 is a patch release with two pluggable-widget fixes and one `brain` fix.

## What's fixed

**Data grid drop-down filters build without CE0463.** Every drop-down filter mxcli created failed `mx check` with "the definition of this widget has changed". Its empty-option caption is now written as Studio Pro writes it: absent while `filterable` or `multiSelect` hides it, and the widget's default text while it is visible. Measured on mx check 11.14.0, 68 pages copied from the test app went from 9 × CE0463 to 0.

**MDL-WIDGET56 judges only the widget mode you chose.** The required-setting warning that v0.33.0 introduced reported the properties of modes the statement did not use: a combo box bound with `attribute:` was warned about 12 properties of the association and database modes. It now judges a widget's hide rules with the values `exec` writes, and counts a property set through its MDL keyword as set.

**`brain capture --from-json` takes `accepts`, `changes` and `partly_meets`.** A batch item can now record a decision that accepts a lint finding, or changes or partly meets a requirement, in the same `<value>[:<reason>]` form the flags use.

## Upgrading

Download the `v0.33.1` binary for your platform from the [release page](https://github.com/mendixlabs/mxcli/releases/tag/v0.33.1):

```bash
curl -fsSL -o mxcli \
  https://github.com/mendixlabs/mxcli/releases/download/v0.33.1/mxcli-linux-amd64
chmod +x mxcli && sudo mv mxcli /usr/local/bin/
```

Then refresh a project's skills and commands with `mxcli init --sync-skills`. Nothing in your scripts needs to change, and the catalog schema is the same as in v0.33.0.
